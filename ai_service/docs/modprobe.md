# Modprobe and Module Dependency Management

## Automatic Dependency Resolution
`modprobe` intelligently adds or removes modules from the Linux kernel. Unlike `insmod`, which requires explicit paths and loaded dependencies, `modprobe` parses pre-indexed dependency databases (`modules.dep.bin`) generated by `depmod`.

## Configuration Directories
Modprobe configuration files reside in:
- `/etc/modprobe.d/*.conf`: System administrator custom overrides.
- `/usr/lib/modprobe.d/*.conf`: Distribution package defaults.
- `/run/modprobe.d/*.conf`: Ephemeral runtime configurations.

## Blacklisting Modules
Modules can be prevented from automatic loading using blacklist directives in `/etc/modprobe.d/blacklist.conf`:
```
blacklist <module_name>
install <module_name> /bin/false
```
The `install <module> /bin/false` pattern overrides alias loading and stops user space or udev from activating the hardware driver.
