# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** open a public issue.

Instead, please send an advisory email directly to:
**`anzzzerkhan@gmail.com`**

Include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept (e.g., shell command, HTTP request payload).
- Any proposed remediation or patches.

You will receive an initial response within 48 hours. Validated vulnerabilities will be patched on a dedicated security branch and disclosed responsibly with appropriate credit.
